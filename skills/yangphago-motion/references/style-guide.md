**화면 구성**
- 한 화면에 **한 문구**(1~6단어), **정중앙**, 여백 70% 이상
- 글자 크기: 핵심 단어 1개는 180~260px, 문장은 60~90px (1920×1080 기준)
- 배경은 단색 블랙 / 단색 화이트 / 블랙 + 아래쪽 보라 방사형 글로우, 세 가지만 사용
- 하단에 아주 작은 회색 크레딧 한 줄(14~16px)은 허용, HUD·테두리·진행바는 쓰지 않음

**정밀 분석에서 확인된 주의점**
- 분석은 화면만 측정했고 음악 동기화는 미검증 → 박자 맞춤은 우리 규칙(킥·스네어 히트)으로 정함
- 주석 구간 중앙값 1.5초는 등장·유지·퇴장 포함값. **읽기 시간으로 쓰지 말 것**
- 샘플은 짧은 영문. 한국어 **문장(8자 이상)만 2박**, 단어는 1박·나열은 반 박 연타 (3박 이상 붙잡으면 역동감이 죽음 — 2026-10-05 일본 30초 v1 피드백). 받침 글자 블러 가독성은 stills로 확인
- 57032891처럼 최종 읽기 순서와 등장 순서가 다를 수 있음(`BRING` 먼저) → 강조어를 먼저 띄우는 연출 가능
- easing 원본은 미확인. 감속형(`eoE`)을 출발값으로 사용

**리듬**
- 히트(글자가 박히는 순간)를 킥·스네어에 맞춤. 박자 일치율 최고 62999763 = 75%
- 흐름: **등장(반 박) → 유지(반 박~1박) → 퇴장 또는 교체(4~6프레임)**. 퇴장은 대부분 컷(즉시)
