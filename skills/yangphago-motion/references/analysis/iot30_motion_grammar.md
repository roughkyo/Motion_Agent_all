# IoT 30초 레퍼런스 정밀 분석 → v2 엔진 기본값

대상: `스킬없이iot30.mp4` (640×360 · 30fps · 30초 · 90BPM). 스킬 v1 없이 `example_infostyle_iot30.html`을 직접 짜서 만든 영상.
목적: "텍스트만 나오는 정적인 결과"와 이 영상의 차이를 수치로 밝히고, 그 차이를 json만으로 재현할 수 있게 엔진 기본값으로 넣는다.

## 1. 분석 방법 (두 갈래)
| | 실제 영상 측정 | 원본 HTML 재렌더 계측 |
|---|---|---|
| 해상도(시간) | 1프레임 = 33.3ms (30fps가 물리적 한계) | **Δt = 1/600초 = 1.67ms** (18,000샘플) |
| 방법 | 900프레임 전부: 밝기·강조색 면적·전경·윤곽 밀도·요소 수(연결 덩어리)·프레임 차이·위상상관 흔들림 | 페이지의 그리기 함수(T·R·C·P·L·slam·pill…)를 감싸 매 샘플 모든 호출의 글자·화면 좌표·크기·불투명도·블러를 기록 |
| 결과 파일 | `iot30_frame_metrics.csv` | `iot30_probe_600hz.txt` |
- 재렌더가 원본과 같은지 검증: 30fps로 다시 뽑아 원본과 프레임별 비교 → 강조색 면적 상관 **1.000**, 프레임 차이 **0.999**, 시간 어긋남 **0프레임**. 차이는 원본에 쓰인 Pixabay 벡터 3장(노트북·서버·DB) 부재뿐
- 그래서 1/600초 계측값은 원본 영상의 실제 움직임 곡선이다 (영상 파일로는 33ms보다 촘촘히 볼 수 없으므로 생성 코드를 계측)

## 2. 스킬 v1 결과물과의 차이 (같은 측정기, 본문 구간)
| 지표 | 레퍼런스 | 스킬 v1 (테슬라 15초) | v2 재현 (json만) |
|---|---|---|---|
| 한 화면 요소 수 (중앙 / 75%) | **16 / 20** | 1 / 2 | 16 / 20 |
| 윤곽 밀도 | 2.78% | 0.86% | 2.88% |
| 정지 프레임 비율 | 37% | **76%** | 32% |
| 흰 배경 프레임 | 0% | 33% | 0% |
| 강조색 면적 | 3.6% | 1.0% | 3.7% |
| 그리기 호출 중 도형 비율 | 62~88% (장면별) | 거의 0 | 동일 구조 |
→ 원인은 '움직임 속도'가 아니라 **화면 구성**: v1은 한 화면 한 문구(정중앙 100~240px), 레퍼런스는 머리글 + 다이어그램·표·아이콘 + 작은 라벨(중앙 34px)로 화면을 채운다.

## 3. 움직임 문법 (1/600초 계측값)
### 타이밍
- 모든 등장은 **16분음표 격자**에 맞춤: 격자 오차 중앙 21ms(대부분 1.5ms — 렌더 반올림), 의도적 엇박은 0.2·0.3박 지연
- 텍스트 등장 99회 / 본문 25.33초 = **3.9개/초**. 연속 등장 간격 중앙 73ms (한 박에 여러 요소가 겹쳐 등장)
- 장면당 새 요소: 2.5~6.5개/박 (훅 2.5 · 릴레이 3.0 · 열쇠 3.8 · 시연 2.7 · 입력 6.5 · 자동기록 4.2 · 경고 3.0)
- 장면 길이: 4박(훅·경고) 또는 6박, 본문 38박 = 7장면 → **장면 하나 2.7~4초**
- 전환: 장면 경계마다 와이프 **338ms**(경계 중심 ±169ms), 종류 순환 slash → curtain → shutter

### 등장 곡선
| 동작 | 측정 | 엔진 기본값 |
|---|---|---|
| slam(제목·결론) | 시작 배율 2.1~2.2 → 1% 이내 정착 **100~115ms**, 불투명 25ms(1프레임) | `slam` from 2.2, d .22박 |
| 작은 slam(본문 결론) | 시작 1.56~1.75 → 정착 80~100ms | `o.from: 1.6~1.8` |
| 카드 | 시작 1.47~1.49 → 정착 93~147ms, 회전 복원 0.4박 | `cards` |
| 표·주소창·코드상자 | 불투명 78ms, 옆/아래에서 57~120px 미끄러짐, 정착 300~600ms | `table` `urlbar` `codebox` |
| 마스크 상승(부제) | 0.3~0.4박 | `reveal` |
| 노드 배지 | eoB(오버슈트) 0.35박, 노드 간 0.5박 | `flow` |
| 위치 | 킥 줌(1.2%) 때문에 위치는 **계속 미세하게 숨쉼** → 완전 정지 샘플 0% | 카메라 기본값 |

### 크기 위계 (px, 1920×1080)
훅 190 · 제목 96(태그 있으면 72) · 결론 52~70 · 노드 라벨 44 · 부제 34~46 · 본문 라벨 26~32 · HUD 20~22
→ 큰 글자는 화면당 1개, 나머지는 작고 많다. **중앙값 34px**

### 카메라·후처리
- 흔들림: 스네어 7px(감쇠 90ms) + 임팩트 28px(250ms) · 줌: 킥 1.2%(120ms) + 임팩트 4%
- 플래시: 첫 프레임 0.85 + 임팩트마다 1.0(160ms) · 글리치: 임팩트 + 경고 장면 스네어 직후 0.1초
- 상시 레이어: 점 격자(킥에 맞춰 0.07→0.15) · 비네트 · 필름 그레인 7% · HUD(모서리·제목·REC·라벨·타임코드·진행바)
