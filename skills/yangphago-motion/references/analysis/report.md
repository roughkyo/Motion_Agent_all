# 모션그래픽 샘플 정밀 분석

분석일: 2026-10-05. 대상: `motion_graphic_sample`의 MP4 10개.

## 1. 분석 범위와 결과

10개 영상 전체를 디코딩하여 12,737프레임의 화면 변화량을 측정했다. 영상 트랙의 총 길이는 353.011초(5분 53.011초)이다. 0.25초 간격의 검토 이미지 1,413장을 추출하고, 이를 시간 순서로 묶은 연속 이미지 27장과 전체 흐름 이미지 10장을 시각적으로 검토했다. 대표 동작 10구간은 원래 프레임 간격으로 PNG 579장을 추가 추출했다. 대표 구간의 요약 이미지는 약 0.08~0.10초 간격이며, 모든 대표 PNG에는 원본 프레임 번호가 있다.

배경이 한 프레임 사이에 크게 바뀌는 35개 시점은 전후 원프레임 70장을 추가 추출하고 직접 대조했다. 이 35개는 큰 명도 전환을 확인한 부분집합이다. 모든 편집 컷, 모든 배경 변경 또는 모든 문구 교체의 총수가 아니다. 어두운 배경끼리 바뀌는 전환과 같은 배경 위의 문구 교체는 별도 수동 주석에 포함했다.

영상의 내용을 182개 문구·동작 구간으로 정리했다. 전체 주석 구간 길이의 중앙값은 1.500초다. 이는 각 영상의 인트로·종료 화면·공백·등장·유지·퇴장이 포함된 값이다. 편집 컷 길이의 중앙값이나 독자가 문장을 읽을 수 있는 시간으로 사용하면 안 된다.

이 샘플의 중심은 키네틱 타이포그래피, 즉 글자와 단어에 움직임을 주는 표현이다. 일반적인 설명 영상 전체의 제작 규칙으로 확대하지 말고, 텍스트 모션의 참고 자료로 사용해야 한다.

검토 진입점: [영상별 전체 구간표](timelines.md), [182개 구간 CSV](annotated-segments.csv).

## 2. 측정 방법과 정밀도

| 자료 | 방법 | 해석 범위 |
|---|---|---|
| 영상 정보 | ffprobe의 스트림·컨테이너 정보 | 해상도·프레임률·영상 프레임 수·오디오 스트림 유무 |
| 전체 프레임 시각 | 각 프레임의 best_effort_timestamp_time | 원본 표시 시각. 번호는 0부터 시작 |
| 전체 화면 변화량 | 원래 프레임 간격, RGB 256×144 축소 | 화면 전체의 변화. 개별 요소 이동 거리나 속도가 아님 |
| 검토 JPEG | 4fps, 가로 640px | 시간 흐름과 문구·구성 확인. 표기 시각은 재표본화 격자의 근사값 |
| 대표 PNG | 선택 구간의 원래 프레임 간격, 640×360 | 시간 간격은 원본과 동일. 공간 해상도는 축소됨 |
| 수동 구간표 | 4fps 이미지 시각 검토 | 시작 시각은 통상 ±0.25초 수준. 읽기 완료 시각이 아님 |
| 배경 전환 CSV | 큰 변화 후보의 원프레임 전후 대조 | 해당 변화가 일어난 프레임의 PTS. 편집 컷인지 키프레임인지 확정 불가 |
| 대표 전경 범위 | 지정 ROI 안의 밝고 무채색에 가까운 픽셀 | 임계값에 따른 전경 프록시. 실제 레이어 경계가 아님 |

전체 화면 수치의 정의:

- `mean_absolute_rgb_difference_0to1`: 이전 프레임과 RGB 절대 차이의 평균. 값이 0이면 축소된 두 프레임이 같다.
- `changed_area_fraction_threshold_0.08`: 픽셀별 평균 RGB 차이가 0.08을 넘는 화면 면적 비율.
- `histogram_total_variation_0to1`: RGB 히스토그램 분포의 변화량. 요소가 움직여도 색 분포가 유지되면 작을 수 있다.
- `mean_rgb_0to1`: 화면 RGB의 평균. 흰색·검은색 배경 교체를 확인하는 보조값.

자동 후보 조건은 평균 차이 >0.12, 또는 평균 차이 >0.035이면서 히스토그램 차이 >0.22이다. 0.2초 이내 후보는 평균 차이가 큰 하나로 묶었다. 이 조건은 컷 검출의 성능을 검증한 표준값이 아니라 이번 분석용 탐색 조건이다. 글리치, 큰 글자, 플래시도 후보로 잡힌다. 후보가 없다는 사실은 컷이나 문구 전환이 없다는 뜻이 아니다.

대표 구간 수치는 x=화면 폭의 10~90%, y=높이의 30~70% ROI에서 평균 RGB >150/255이고 채널 최대·최소 차이가 90/255보다 작은 픽셀을 측정했다. 흰 배경, 연기, 글로우, 밝은 장식이 포함되면 개별 글자를 분리하지 못한다. 특히 `62999763`의 흰 배경 구간에서는 이 수치를 글자 추적으로 사용하지 않는다. `60608725`, `60806086`의 연기 배경도 시각 검토를 우선한다.

프레임의 시각을 안다는 것과 효과의 시작·끝을 정확히 판정했다는 것은 다르다. 원프레임을 추출한 대표 구간에서도 효과 시작·완료의 서술이 약 0.1초 간격 요약 이미지에 근거하면 근사값으로 적었다. 이번 작업에서는 글자별 전 구간 궤적 추적, 광학 흐름, easing 함수 피팅, 음성·음악 청취 및 박자 분석을 수행하지 않았다. 10개 모두 오디오 스트림은 있지만 음향 동기화 여부는 미검증이다.

### 11971627: 짧은 텍스트 프리셋을 빠르게 보여 주는 구성

검정·흰색·보라 빛 배경을 바꾸며 짧은 제목과 설명 문구를 교대로 제시한다. 단어 강조, 타이핑 커서, 별 장식, 글자별 흐림이 서로 다른 동작으로 쓰인다. 7초대에는 세로 모바일 카드가 들어가므로 모든 구간이 텍스트만으로 이루어진 것은 아니다.

대표 구간 23.8~25.5초에서 `Signal`은 앞쪽 글자부터 흐려져 퇴장하고, 배경과 문구가 바뀐 뒤 `Neural`은 뒤쪽 글자에 흐림이 남아 있다가 선명해진다. `Neural`도 끝에서는 앞쪽부터 흐려진다. 전체 문장에 동일한 블러 값을 동시에 적용하면 이 순차 효과를 재현하지 못한다.

원프레임에서 확인한 배경 전환 예: 6.006초(f180), 7.007초(f210), 11.011초(f330), 11.845167초(f355). 특히 11.011~11.845167초의 흰 배경은 0.834167초만 지속하며, 문장은 이 전환을 넘어서 계속 이어진다. 배경 구간 길이와 문구 구간 길이가 다르다는 직접적인 사례다.

스킬 참고: 짧은 제목, 단어 강조, 글자별 흐림을 각각 독립된 동작으로 정의하고 문구 교체와 배경 교체를 따로 제어한다.

### 57032891: 여러 줄과 개별 글자의 순차 조립

굵은 흰색 글자에 빨강·파랑 포인트를 주고, 낮은 밝기의 배경 질감을 유지한다. `WE BRING THE TEXT TO LIFE`는 먼저 `BRING`이 나타난 뒤 앞 단어와 다음 줄이 추가된다. 최종 읽기 순서와 실제 등장 순서가 일치하지 않는다.

원프레임 요약에서 0.200초에는 `BRING`, 0.400초에는 위 줄과 두 번째 줄 일부, 0.700초에는 세 번째 줄 일부, 1.000~1.100초에는 전체 문구가 거의 안정된 모습이다. `YOU GOT THIS`에서는 개별 글자 크기·각도가 다르고, `HELLO! EVERYONE`의 퇴장은 문구 묶음을 기울여 측면으로 보내는 모습이다. `SHADOW`는 반사 이미지와 글자 폭 변화가 함께 보인다.

전경 프록시의 전체 범위는 0.500초에 폭 0.4266W, 1.000초에 0.4016W다. 이 값에는 글자 추가가 섞여 있으므로 스케일 곡선으로 피팅하면 안 된다. 거의 완성된 1.000~1.500초 구간에서는 폭이 0.4016W로 유지된다.

스킬 참고: 글자·단어·줄·문구 묶음의 네 단위가 필요하다. 이 파일의 주석 구간 중앙 길이는 4.5초로, 1초대 타이틀 중심 파일의 리듬을 그대로 적용할 수 없다.

### 57523104: 줄별 공간 배치와 굵기 대비

검은 배경과 흰 글자를 중심으로 굵은 제목과 가는 보조 줄을 섞는다. `SUCCESS / LOVES / SPEED`는 줄별로 측면에서 들어와 중앙에 쌓인다. 2.600초에는 첫 줄, 2.700초에는 두 번째 줄, 2.800초에는 세 번째 줄이 보이며 2.900~3.100초에 정렬이 안정되는 모습이다. 이 시각은 요약 이미지에 따른 근사 관찰이다.

`DREAM BIG / WORK HARD / STAY FOCUSED`는 줄별 수직 이동을 사용한다. `BELIEVE IN`의 퇴장도 줄을 아래쪽으로 보내며 화면 가장자리에서 잘린다. 12.5~15.5초의 RGB 글리치는 다른 흑백 구간과 구별되는 강조 효과다.

스킬 참고: 줄별 지연 시간, 줄 간격, 굵기 대비, 화면 밖 퇴장을 별도 항목으로 둔다. 모든 구간을 글리치 스타일로 통일하면 원본의 대비를 잃는다.

### 60153473: 색 잔상을 동작에 결합한 구성

RGB 분리, 다색 리본, 외곽선 잔상, 텍스트 늘이기가 가장 뚜렷하다. 2초대 `MOTION DESIGN`은 매우 큰 상태에서 작은 두 줄로 수축한다. `DYNAMIC`은 외곽선 잔상을 거쳐 채워진 글자로 바뀐다. `LUMORA`는 텍스트에서 수직으로 늘어난 다색 잔상이 생기며, 후반에는 기울임·복제·접힘처럼 보이는 변형이 더해진다. 실제 3D 레이어나 카메라 사용 여부는 영상만으로 확인할 수 없다.

대표 8.2~10.1초 `blur`는 작은 흐린 상태에서 커지고 선명해진다. 8.200초의 ROI 경계 에너지 프록시는 0.000992, 9.866667초에는 0.016002다. 약 16.1배 증가했지만 글자 크기·대비·RGB 분리 변화가 모두 영향을 주므로 블러 반경이 16배 줄었다는 뜻은 아니다.

스킬 참고: 기본 위치·크기 동작 위에 RGB 오프셋, 잔상 수, 잔상 길이, 외곽선/채움 상태를 결합하는 효과로 기술한다. 한 장의 이미지에서 보이는 색 번짐만 복사하면 시간에 따라 수축하는 잔상은 재현되지 않는다.

### 60608725: 첫 단어 강조 후 문장을 완성하는 구성

청회색 연기가 움직이는 배경 위에 작은 문구를 놓는다. 첫 단어가 크게 나타났다 작아지고, 뒤 문구가 타이핑되거나 단어별로 들어온다. 강조색은 현재 등장하는 일부 글자·단어에 머물렀다가 흰색으로 바뀐다.

대표 0~1.5초에서 0.080초에는 흐린 `t`, 0.320초에는 큰 `text`, 0.400초에는 작은 `text`, 0.560~0.880초에는 뒤 글자들이 추가되고 1.040초에는 흰색 `text animation`이 완성된 모습이다. 등장 동작 안에 글자 공개와 크기 축소가 함께 있다.

스킬 참고: 첫 단어 강조 → 작은 문구 크기로 정착 → 뒤 문구 공개 → 읽기 유지 → 순차 퇴장으로 기술한다. 연기 배경의 움직임을 글자 움직임으로 측정하지 않도록 영역을 분리해야 한다.

### 60806086: 연기 배경 위의 문구 교체와 강조색 변화

`60608725`와 비슷한 동작군이지만 보라색 연기와 문구·순서가 다르다. 동일한 원본 프로젝트나 동일한 설정을 사용했다고 단정할 근거는 없다. `Let’s start…`는 넓은 자간을 사용하며, `You can write whatever you want`에는 기울임과 색 강조가 더해진다.

대표 17.5~19.7초에서 18.018초에는 이전 문구와 새 녹색 글자가 잠깐 겹친다. 18.118~18.418초에는 큰 녹색 `See`, 18.519~18.919초에는 뒤 문구 타이핑, 19.019초에는 흰색 전체 문구, 19.419~19.620초에는 작은 크기로 정착한 모습이다.

스킬 참고: 앞 문구가 완전히 사라진 다음 시작하는 전환과, 짧게 겹쳐 교체하는 전환을 구분한다. 녹색에서 흰색으로 바뀌는 시점은 문구 공개 및 크기 동작과 따로 기록한다.

### 60944035: 외곽선·채움 상태를 바꾸는 구성

검은 배경 위에 어두운 보라색 외곽선과 흰 채움 글자를 교대로 표시한다. 같은 문구의 일부 높이만 흰색으로 보이는 수평 띠가 지나간다. `WAKE UP BRO!`는 잠깐 크게 확대됐다 기본 크기로 돌아온다. 밝은 요소의 면적이 작아 자동 컷 후보는 24.400초 한 건만 잡혔지만 수동으로는 18개 구간을 구분했다.

### 62295607: 대형 반투명 글자의 축소와 순차 공개

검은 배경의 푸른 빛, 흰 배경, 별 모양 장식을 사용한다. 도입의 `Clean`, `text`, `animation`, `preset`은 큰 반투명 상태로 등장해 작아지며 선명해지는 모습이다. 중간 문장은 단어별 등장·퇴장을 사용한다. 별 장식은 가로 폭과 명암이 변하지만 실제 3D 회전값은 확인하지 않았다.

스킬 참고: 문구 전체 축소, 글자별 공개, 단어별 강조, 장식의 반복 동작을 구분한다. 긴 설명 문구에 도입의 대형 단어 동작을 그대로 적용하지 않는다.

### 62999763: 흩어진 글자 조립과 자간 수축

짧은 타이틀이 약 1초 단위로 자주 바뀐다. `Ready`, `Set`은 큰 자간에서 촘촘한 상태로 정착한다. `Make`, `Fast`는 글자들이 서로 다른 위치와 크기로 펼쳐졌다 정렬된다. 작은 문장에는 별·화살표처럼 보이는 컬러 장식이 붙는다.

스킬 참고: 글자별 위치·크기·자간·변형이 섞인 표현이다. 전체 단어에 단일 스케일만 적용하면 조립 과정을 재현하지 못한다. `beat`는 회전도 사용하므로 위치 이동만으로 분류하지 않는다.

### 63211445: 왼쪽을 고정한 타이핑과 선택 영역

글자가 추가돼도 문구 시작 위치를 유지한다. 화면 중앙 주변을 차지하는 왼쪽 정렬 문구, 선택 박스·작은 핸들, 파란 선택 영역, 밝은 선택 영역, 분홍색 단어 강조가 서로 다른 구간에서 나타난다. 여러 줄 문구는 줄바꿈과 함께 타이핑된다.

스킬 참고: 전체 텍스트의 최종 배치를 먼저 정한 뒤 글자를 공개하되 왼쪽 시작 위치와 줄바꿈을 유지한다. 선택 영역은 텍스트 폭에 맞추고, 현재 단어 강조는 전체 문장 배경과 구분한다.

### 스킬에 필요한 입력과 기록 구조

필요한 입력은 문구, 사용 목적, 결과 영상 크기·프레임률, 동작 선택, 등장·유지·퇴장 시간, 강조 단어다. 동작 단위는 글자/단어/줄/문구 중 하나로 명시한다. 글자 공개를 만들 때는 최종 줄바꿈과 배치를 먼저 정해야 한다. 문구 일부를 매 프레임 새로 중앙 정렬하면 `63211445`와 같은 왼쪽 고정 타이핑을 재현할 수 없다.

각 참고 동작에는 파일명, 근거 프레임, PTS, 관찰한 상태 변화, 측정 방법, 추정 설정, 정밀도를 함께 저장한다. 화면 좌표는 x/W·y/H, 길이는 W·H의 비율로 기록하고, 시간은 초로 저장한다. 24fps 파일의 프레임 수를60fps 영상에 그대로 적용하면 동작 시간이 달라지므로 출력 프레임 수는 초×출력fps로 환산한다.

현재 단계에서 스킬의 검증 기준으로 사용할 수 있는 예:

- 왼쪽 고정 타이핑: 글자 공개 중 시작점과 줄바꿈이 움직이지 않는지 확인.
- 중앙 축소: 텍스트 크기가 줄어도 지정 중심점이 유지되는지 확인.
- 글자별 흐림: 정한 순서대로 흐림이 전파되고, 유지 구간에는 글자가 선명한지 확인.
- 다중 줄: 조립 완료 뒤 줄 간격과 화면 밖 잘림을 확인.
- 선택 영역: 공개된 문구에 맞춰 범위가 늘어나고, 강조 단어가 실제 문구와 일치하는지 확인.
- 프레임률 변경: 같은 초 단위 시간표로24/30/60fps 출력의 동작 길이가 유지되는지 확인.

샘플은 짧은 영문 홍보 문구 중심이다. 한국어 수업 설명 문장에 같은1초 리듬과 큰 자간을 그대로 적용할 근거는 없다. 한글 줄바꿈, 읽기 시간, 자간, 받침이 있는 글자의 블러 가독성은 실제 한국어 출력으로 검증해야 한다.
